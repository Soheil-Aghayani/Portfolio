# Soheil Aghayani - Portfolio Website

This repository contains the source code for the personal portfolio website of Soheil Aghayani.

## Overview

The website is a static single-page application designed to showcase Soheil's professional background, education, research, and skills. It features a modern, responsive design with interactive elements and an "OS-like" overlay including a terminal, notes application, and games.

## Features

-   **Hero Section:** Dynamic typing effect and animated background.
-   **Education & Experience:** Timeline and card-based layouts for professional history.
-   **Research & Publications:** List of publications and conference papers.
-   **Interactive OS Interface:**
    -   **Terminal:** Interactive terminal simulation (`> Hello_World`).
    -   **Notes Application:** Create and manage notes locally.
    -   **Game Center:** Includes games like Blackjack and Snake.
    -   **Draggable Windows:** Simulated desktop environment.
-   **Responsive Design:** Optimized for both desktop and mobile viewing.

## Technologies Used

-   **HTML5**
-   **CSS3** (Custom variables, Flexbox, Grid, Animations)
-   **JavaScript** (Vanilla JS for interactivity and OS simulation)
-   **Google Fonts** & **Material Symbols**

## How to Run

Since this is a static website, you can view it by simply opening the `index.html` file in any modern web browser.

1.  Clone the repository:
    ```bash
    git clone <repository-url>
    ```
2.  Navigate to the project directory.
3.  Open `index.html` in your browser.

## Project Structure

-   `index.html`: Main entry point.
-   `css/`: Stylesheets (`os.css`).
-   `js/`: JavaScript logic for the site (`os.js`, `terminal.js`, `notes.js`, `app.js`).
    -   `js/games/`: Game logic (`blackjack.js`, `launcher.js`, `snake.js`).
-   `*.svg`: Icon assets.
